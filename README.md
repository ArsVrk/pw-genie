# Джини PW

Гайд, база скілів і калькулятор джинів для сервера CyberPW.

**Сайт:** https://arsvrk.github.io/pw-genie/

- **Калькулятор** — вікно джина як у грі: рівень, очки удачі, характеристики, стихії, спорядження, дерево скілів із фільтрами
  та картки вибраних скілів із бонусами від сили й спритності.
- **Спорядження** — усі речі для джина й рецепти.
- **Білди** — приклади збірок; згодом — білди гравців.
- **Про джинів** — гайд для новачків і поради по класах.
